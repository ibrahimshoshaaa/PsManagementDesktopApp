# PS Management Desktop Offline

نسخة ويندوز مستقلة تعمل بقاعدة Drift/SQLite على الكمبيوتر. في أول تشغيل اكتب اسم المحل وحدد كلمة سر الأدمن. حسابات الكاشير تُضاف من الإعدادات.

- ملف البيانات `ps_app_offline.sqlite` موجود في مجلد `Offline` داخل مجلد بيانات التطبيق للمستخدم على ويندوز.
- تبدأ النسخة بقاعدة مستقلة. بيانات Firebase وملف SQLite للنسخة المتزامنة لا تنتقل تلقائيًا.
- إدارة الجلسات والتربيزات والبوفيه والمخزون والعملاء والشيفتات والتقارير تعمل على بيانات هذا الكمبيوتر. متابعة المحل من الموبايل وطلبات العملاء عبر QR تتطلب النسخة المتزامنة.
- تصدير التقارير يتم محليًا. يستخدم PDF خط Tahoma المثبت على ويندوز.

## بناء نسخة ويندوز

```sh
flutter create . --platforms=windows
flutter pub get
dart run build_runner build
flutter build windows --release
```

يُرفع ملف ويندوز المضغوط إلى Artifacts بعد نجاح GitHub Actions.

## ترخيص العملاء

من صفحة بناء ويندوز نزّل ملف **PS-License-Manager** من Artifacts، فك الضغط،
وشغّل `PS-License-Manager.exe` على جهازك. الأداة مستقلة عن برنامج العميل
ولا تحتاج تثبيت Python.

1. أول مرة اضغط **فتح أو إنشاء مفتاح الإصدار** وحدد كلمة السر.
2. اضغط **نسخ المفتاح العام**، وضيفه إلى GitHub في
   **Settings → Secrets and variables → Actions → Variables** باسم
   `PS_LICENSE_PUBLIC_KEY`، ثم أعد بناء برنامج العميل على فرع `codex/desktop-offline`.
3. خُد معرّف الجهاز من العميل، واكتب المعرّف وعدد الأيام في الأداة واضغط
   **حفظ ملف الترخيص**. ابعت له ملف `.pslicense` عشان يفتحه من شاشة التفعيل.
   التجديد بنفس الخطوات من زر **الترخيص والتجديد** عند الأدمن.

احتفظ بنسخة احتياطية من مفتاح الإصدار المشفّر في
`%USERPROFILE%\.ps-desktop-licensing\issuer.pem` ومن كلمة سره. العميل يحتاج
نسخة البرنامج وملف الترخيص. أداة الإصدار ومفتاحها للاستخدام عندك.
المدة تبدأ من إصدار الترخيص. الكود بيتحقق منه محليًا، وإلغاء كود صادر قبل نهايته
عن بُعد غير متاح. البناء من غير المفتاح العام ينتج نسخة لا تقبل التفعيل.

أداة سطر الأوامر الاختيارية موجودة في `tools/issue_license.py`.
